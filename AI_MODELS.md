# Использование ИИ

| Модель | Инструмент | Применение |
| --- | --- | --- |
| GPT-6 (OpenAI) | Codex | Предложение идеи планировщика, реализация CLI и расчёта, подготовка демо-данных, тестов и workflow, разбор результатов локальных проверок и подготовка документации. |

Приложение и оба workflow выполняются на обычном Python. Расчёт отчёта использует входной CSV, заданную дату и дневной бюджет. Для работы приложения не нужны модели, внешние API или ключи.
